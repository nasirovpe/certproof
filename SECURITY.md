# Security Policy

## Educational & Experimental Prototype

CertProof is an educational portfolio and reference architecture exploring decentralized document verification with zero-knowledge-style client-side hashing, SIWE session management, and EVM smart contracts.

> [!WARNING]
> This codebase is unaudited and is not intended or supported for production use, high-value asset handling, or mainnet deployment. No formal security audit has been performed on the smart contracts or application logic.

## Supported Scope & Support Commitment

- This project is maintained solely as an educational demonstration.
- There is no commercial service level agreement (SLA), 24/7 emergency response team, dedicated security operations center, or bug bounty program.
- Do not deploy these smart contracts to Ethereum mainnet or deposit real monetary funds. Always use isolated local development networks (Anvil) or testnets (Sepolia).

## Reporting Security Observations

If you identify a potential security issue, flaw in cryptographic reasoning, or vulnerability in this educational project:

1. Open a GitHub Security Advisory (or standard GitHub Issue marked `[Security/Educational Feedback]` if advisories are unavailable on your fork).
2. Clearly describe the conceptual vulnerability, affected components, and potential impact.
3. Do not include exploit scripts against live public networks or expose real private keys, passwords, or personal credentials.

Constructive reviews and academic feedback aimed at improving decentralized security design patterns are welcomed.
